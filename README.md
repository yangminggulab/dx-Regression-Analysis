第一章开头直接写入功能结构树，按研究对象、描述、预测、推断、模型检查与工具链组织。参考 [Cosma Shalizi 的 CMU Modern Regression（2015）](https://www.stat.cmu.edu/~cshalizi/mreg/15/) 和 [Larry Wasserman 的同名课程（2017）](https://www.stat.cmu.edu/~larry/=stat401/)。中文功能分组和本教材章次映射为个人整理，并非对外部课程分类的逐字翻译。第四、五章仅出现在全书功能图，正文范围为前三章。

`作业.tex` 集中保存三次作业，第二章分组含第一次、第二次，进入第三章换组保存第三次（含第二章补充阅读）。每次作业一个 section；共 16 组完整阅读笔记、11 道指定习题（1–6、8、9、10、11、18），每题有完整题干、解答和提示。未指定的其余 49 道不自动并入本轮作业，原 60 题解答文件保留在课程工作区。

## 工程与编译

- `main.tex`：总入口。
- `第一章.tex`、`第二章.tex`、`第三章.tex`：每章独立文件。
- `作业.tex`：集中作业。
- `elegantbook.cls`、`reference.bib`、`images/`：与数理统计相同的模板和必要资源。
- `回归分析前三章.pdf`：28 页成品。
- `原文条目索引.md`、`条目清单.json`：教材原编号、已有页文件与源码标签。
- `校勘记录.md`：数学条件、维度、记号及原作业题干补全记录。
- `原文校验清单.json`、`verify.py`、`校验记录.md`：原文保护与公式验证。

作者为“东邪”；座右铭沿用数理统计。封面素材为 Manim 项目 `数学图片素材/普朗克辐射谱.png`，作为函数关系的曲线示意，未将其当作实际回归拟合或数据分析结果。原图完整复制，保持比例；封面横带、作者栏、标志、颜色和环境来自原模板。模板文件 SHA-256 与数理统计原件一致。

本地具备 XeLaTeX、latexmk 和 Biber 时：

```bash
bash build.sh
```

上传整个目录至 Overleaf，主文档选 `main.tex`，编译器选 **XeLaTeX**；所有图片和章节均用相对路径，不依赖机器上的外部文件。未实际登录 Overleaf 编译；完整工程已在本地编译并逐页检查。内置单文件编译器未能载入 `images/cover.png`，因此其预览不代表整套工程验收。

核验脚本需 Python 3 与 NumPy，执行 `python3 verify.py`。在原课程工作区会额外核对 82 个原文件 SHA-256；在独立克隆目录明确跳过该项，其他结构与数学检查继续运行。
